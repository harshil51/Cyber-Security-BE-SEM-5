## 📖 Overview

**CYBERNEXUS** is an interactive, animated, single-page cyber security study platform engineered to help students master university examination concepts (GTU / Undergraduate Cyber Security) through hands-on engagement, real-time attack visualizers, 3D memory flashcards, and structured 10–15 mark model answers.

Built using **Pure HTML5, Vanilla CSS3, and JavaScript**, the entire platform requires **zero external build tools or server dependencies** and operates **100% offline**.

## 📚 Syllabus Coverage

<details open>
<summary><b>Unit 1: Introduction to Cyber Crime & Global Perspectives</b></summary>
<br>

* **Definition & Core Concepts**: Computer as a *Target*, *Tool*, and *Storage Medium*.
* **Historical Evolution**: Mainframe abuse (1960s-70s) $\rightarrow$ Phone Phreaking & 2600 Hz Blue Boxes $\rightarrow$ 1988 Morris Worm $\rightarrow$ Web Expansion $\rightarrow$ Modern APTs & AI Deepfakes.
* **4-Pillar Classification**: Offenses Against *Individuals*, *Property*, *Government*, and *Society*.
* **Global Perspectives**: Transnational jurisdiction clashes, Extradition bottlenecks, and the **Budapest Convention on Cybercrime (2001)**.
* **Planning of Cyber Offences**: The 8-phase **Cyber Kill Chain** (Recon $\rightarrow$ Scanning $\rightarrow$ Weaponization $\rightarrow$ Delivery $\rightarrow$ Exploitation $\rightarrow$ Installation $\rightarrow$ C2 $\rightarrow$ Actions on Objectives).
* **Case Studies**: *WannaCry Ransomware (EternalBlue SMB exploit)*, *Yahoo 3-Billion Account Breach*, *Sony Pictures Cyberattack*.
</details>

<details>
<summary><b>Unit 2: Cybercrime & Social Media, Social Engineering & Botnets</b></summary>
<br>

* **Social Media Ecosystem**: 6-Element attack structure (Victim, Attacker, Platform, Info, Vector, Objective).
* **Social Engineering Psychology**: 6 Human vulnerabilities (*Authority*, *Urgency*, *Fear*, *Greed*, *Trust*, *Curiosity*).
* **Attack Taxonomies**: *Phishing*, *Pretexting*, *Baiting*, *Quid Pro Quo*, *Tailgating*, *Impersonation/BEC*, *Scareware*.
* **Cyberstalking & Legal Protections**: Direct vs Indirect stalking, evidence preservation, and Indian IT Act provisions (Sec 66E, 67, IPC 354D).
* **Cybercrime-as-a-Service (CaaS)**: RaaS, PhaaS, Initial Access Brokers, Darknet markets, and Crypto laundering.
* **Botnet Architectures**: *Centralized C2* vs *Peer-to-Peer (P2P)*, Botnet infection lifecycle, and the **Mirai Botnet (1.2 Tbps IoT DDoS)** case study.
* **Case Studies**: *Twitter 2020 Bitcoin Vishing Compromise*, *Cambridge Analytica Facebook Data Scandal*.
</details>

<details>
<summary><b>Unit 3: Cyber Crime with Mobile & Wireless Devices</b></summary>
<br>

* **Mobile Security Landscape**: Portability risks, OS sandboxing breakdown, **Jailbreaking & Rooting hazards**.
* **Credit Card & Payment Frauds**: Skimming, CNP fraud, POS RAM scraping, and **SIM Swap Fraud step-by-step mechanics**.
* **Mobile OS Hardening**: Registry configurations, application permission audits, and developer option locks.
* **5 Factors of Authentication**: *Knowledge* (Password), *Possession* (Token), *Inherence* (Biometrics), *Location* (GPS), *Behavior* (Dynamics).
* **Wireless Network Attacks**: *Evil Twin Rogue APs*, *Man-in-the-Middle (MITM)*, *ARP Poisoning*, *Wi-Fi Sniffing*, *KRACK (WPA2)*.
* **Bluetooth Threat Triad**: *Bluejacking* (Spam) vs *Bluesnarfing* (Data theft) vs *Bluebugging* (Full remote hijack).
* **Enterprise Mobile Security**: Mobile Device Management (**MDM**), **MAM**, Containerization, and **BYOD** zero-trust policies.
</details>

<details>
<summary><b>Unit 4: Tools Used in Cybercrime & Advanced Malware</b></summary>
<br>

* **Proxy Servers**: Forward, Reverse, Transparent, Anonymous, High-Anonymity (Elite), and Open Proxies; Proxy chaining and mitigation.
* **Anonymizers & Tor Network**: 3-Hop Onion Routing (*Guard $\rightarrow$ Middle $\rightarrow$ Exit*), layered cryptographic encapsulation, and hidden services (.onion).
* **Dark Web Law Enforcement**: **Operation Bayonet** (*AlphaBay takedown & Hansa Market honeypot operation*).
* **Advanced Phishing Techniques**: Typosquatting, IDN Homograph Punycode attacks, Reverse Proxy Phishing (*Evilginx 2FA bypass*), and Quishing (QR Phishing).
* **Password Cracking**: Brute Force, Dictionary, Hybrid, Password Spraying, Credential Stuffing, and Rainbow Tables (*Tools: Hashcat, John the Ripper, Hydra*).
* **Password Hashing & Cryptography**: *Salt*, *Pepper*, Work factor, and comparison matrix (*MD5 vs SHA-1 vs SHA-256 vs Bcrypt vs Argon2id*).
* **Keyloggers & Spyware**: Software API hooks (`SetWindowsHookEx`), Hardware USB dongles, and Kernel rootkits.
* **Malware Classification & Anatomy**: Virus vs Worm comparison and 5-stage anatomy (*Replication, Propagation, Trigger, Payload, Concealment*).
* **Trojans, RATs & Backdoors**: Remote Access Trojans (RATs), banking overlays, and persistence mechanisms.
* **DDoS Attacks & Scrubbing**: Volumetric (Gbps), Protocol (SYN Flood), and Application-Layer (Slowloris) attacks with **Cloud Scrubbing & BGP Anycast** defenses.
</details>

## 🎯 10–15 Mark Exam Master

For undergraduate and university exams (e.g. GTU), each question is pre-formatted with the standard scoring structure:
* **Definition** (2 Marks)
* **Architecture / Concept Box Diagram** (2 Marks)
* **Detailed Working & Mechanisms** (4–5 Marks)
* **Classification & Types** (3 Marks)
* **Countermeasures / Prevention** (2–3 Marks)
* **Conclusion & Real-World Context** (1 Mark)

### Option 1: Direct File Launch
Simply double click [`index.html`](index.html) or open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option 2: Local HTTP Server (Python)
```bash

cd "e:/AA PROJECTS/CS"

# Start a lightweight Python HTTP server
python -m http.server 8080
```
